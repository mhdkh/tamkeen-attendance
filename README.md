# تفقد امتحان التمكين — الدورة الثالثة 2026

صفحة تفقد حضور الطلاب والمراقبين لإدارة التنمية الثقافية وتعليم الكبار (وزارة الثقافة).
تعمل على الموبايل بلا إنترنت بعد تنزيل قائمة المقر، وترفع المسحات إلى «بوابة امتحان التمكين» عند عودة الاتصال.

- **لا يحوي هذا المستودع أي بيانات طلاب أو مراقبين.** البيانات تُنزَّل من البوابة بعد الدخول برمز المقر.
- رابط البوابة في `config.js`.
- عند تعديل أي ملف: غيّر رقم الإصدار في `sw.js` (السطر `var CACHE = ...`) لتتحدّث الأجهزة.
- مكتبة قراءة QR: jsQR (رخصة Apache 2.0، انظر `jsQR-LICENSE.txt`).
